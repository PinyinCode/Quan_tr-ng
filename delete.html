🗑️ Xóa User Thủ Công (Firestore)

Công cụ này giúp xóa nhanh quyền truy cập của user trong Firestore mà không gọi qua Server API (tránh lỗi 429).

Lưu ý: Sau khi xóa bằng công cụ này, user sẽ mất quyền truy cập vào hệ thống. Để xóa sạch hoàn toàn trên Firebase Auth (tránh lỗi email-already-in-use khi đăng ký lại), bạn có thể vào xóa thủ công trên giao diện Firebase Console.
